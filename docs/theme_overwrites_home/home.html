Kodjin CLI Documentation

The Kodjin CLI is a powerful and user-friendly command-line tool designed to streamline the management of FHIR Implementation Guides (IGs) for FHIR servers. It automates downloading, installing, and maintaining IGs, including their complex dependency chains.

Whether you're setting up a FHIR server, updating an installation, or experimenting with IGs, Kodjin CLI simplifies and accelerates the workflow.
